Try each grid

  1. Scroll fast through all rows; sort by a column; search and filter.
  2. Double-click Industry, Country or Notes to edit; edited cells get an orange underline.
  3. Double-click Tags: type in the search box to narrow the list, tick several, press Done. Keyboard: arrows move, Enter ticks, Esc cancels.
  4. Select several rows and use "Apply to selected rows".
  5. Copy cells and paste a block, also from Excel.
  6. Undo an edit with Ctrl+Z (Cmd+Z on the Mac).
